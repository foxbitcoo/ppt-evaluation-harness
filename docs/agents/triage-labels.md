# Triage Labels

| Canonical role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Waiting for initial evaluation |
| `needs-info` | `needs-info` | Missing product or technical information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and suitable for an agent |
| `ready-for-human` | `ready-for-human` | Requires human judgment or implementation |
| `wontfix` | `wontfix` | Deliberately not being actioned |

All engineering Skills must use these labels instead of creating synonyms.
