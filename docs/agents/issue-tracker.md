# Issue tracker: GitHub

Issues and PRDs for this project live in the private GitHub repository
`foxbitcoo/ppt-evaluation-harness`.

Use GitHub Issues as the unique source of truth for requirements, specifications,
tasks, decisions, blockers, and completion state.

## Conventions

- Create, read, comment on, label, and close work through GitHub Issues.
- One Issue represents one independently verifiable unit of work.
- Product specifications may use a parent Issue with linked implementation Issues.
- Important conclusions remain in the Issue body or an ADR, not only in comments.
- Local notes are temporary and do not override GitHub state.
- Pull requests are implementation delivery records, not feature-request intake.
- When a Skill says "publish to the issue tracker", create a GitHub Issue.
- When a Skill says "fetch the relevant ticket", read the Issue and its comments.
