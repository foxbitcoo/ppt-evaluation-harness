# report-index@0.2.0：静态 80 分报告映射

状态：Ready for implementation  
对应 Issue：#30  
底层 Rubric：`query-ppt-rubric@1.1.0`

## 1. 目标

新增一个版本化的报告映射，吸收独立 Presentation 评审流程，同时保持底层原子三态判断、底线检查和证据血缘不变。

本版本是报告层映射，不是新的原子 Rubric，也不是已经校准的市场排名。底层 `GOOD | BAD | UNCERTAIN`、`PASS | FAIL | UNKNOWN`、垂类候选规则与人工 A/B 偏好继续独立保存。

## 2. 输入顺序

1. 完整阅读原始材料、任务要求、统一生成提示词与请求者/受众上下文。
2. 查看整套作品的总览图，判断整体叙事、节奏与一致性。
3. 查看原始尺寸逐页静态图片，检查内容、图文、版式和可读性。
4. 对每套作品独立形成报告映射。
5. 全部作品完成独立映射后，才生成任意 A/B 或多产品比较。

品牌匿名是可选的 Batch 协议，不是强制流程。源文件格式、仓库、作者、工具和技术路线不得影响静态质量判断。

## 3. 静态评分（80）

| 维度 | 满分 | 主要输入 |
| --- | ---: | --- |
| 内容准确与覆盖 | 25 | `task_fit`、`coverage_and_selection`、事实/本页主张 Evidence |
| 叙事与通俗性 | 20 | `narrative_organization`、`audience_fit`、页序与页面角色 |
| 视觉层级与一致性 | 10 | `layout_hierarchy`、`deck_consistency`、场景审美规则 |
| 图文使用 | 10 | `visual_expression`、`image_context_fit`、图表/截图可读性 |
| 可读性与静态完成度 | 15 | `readability`、`visual_finish`、裁切、溢出、遮挡与残留字段 |

分项与总分只使用整数。总分必须严格等于五个分项之和。当前版本不允许 0.5 分，避免未经校准的伪精确。

重大虚构、核心观点反转或关键事实错误可以触发版本化的“内容分上限”候选规则，但不得隐式把整套作品判死，也不得未经样张校准直接启用。

## 4. Presentation 有效性参考（10）

额外给出 0–10 的参考分，判断当前静态页面能否支撑一次现场讲述。它不进入静态 80 排名，也不评价真实播放、动画或演讲者模式。

关注：

- 演讲者能否顺着页面讲下去；
- 观众能否快速抓住每页重点；
- 页面之间是否有停顿和推进；
- 是否拥有完整开头、展开和结尾。

## 5. 独立的编辑、交付与过程信息

下列信息不得进入静态 80 分：

- 可编辑源文件、改字换图、继续创作与重新导出；
- 打开播放、翻页、动画、交互、演讲者模式、跨环境字体和布局；
- 仓库与 commit、输出格式、模型与外部服务、安装准备时间；
- 生成耗时、人工决策、失败、重试、返工、联网和上传要求。

无法通过真实操作核验的能力统一标记为 `UNVERIFIED`，不能因入口、脚本输出或产品声明而判定通过。

## 6. 报告内容

每套作品必须输出：

- 五个静态分项、静态总分和 Presentation 参考分；
- 一至三段主要优点和缺点；
- 最强页、最弱页及页码和可见证据；
- 内容错误与内容缺失两个独立列表；
- 明显版式与可读性问题；
- 静态页面无法判断的能力；
- 场景化推荐标签，例如内容完整、视觉解释、个性、可编辑、现场讲述、快速产出。

同一缺陷必须声明唯一 `deductionOwner`，其他维度只允许引用，不得重复扣分。不可读截图只能作为来源意象或装饰证据，不能算作有效信息展示。

## 7. 垂类与人设边界

通用 80 分只负责报告归一化。教育、经营汇报等垂类规则以及请求者 Profile、受众、使用场景继续按需加载，并保留“为什么该场景需要此规则”的简短解释。

垂类原子规则不因进入报告映射而自动晋升正式 Rubric；仍需来源证据、样张校准和版本审查。

## 8. 状态与兼容性

- 映射版本：`report-index@0.2.0`
- 校准状态：`PROVISIONAL_SCORE_NOT_CALIBRATED`
- 旧版本：`report-index@0.1.0` 只读保留，不覆盖历史记录。
- 任意产品比较必须使用相同的 Rubric、映射版本、静态面协议和兼容输入。

## 9. 验收条件

- `reporting/` 中存在稳定 TypeScript 合同与纯函数校验/聚合；报告层不得改变受信 Runner 的 `src/` 构建身份。
- 测试覆盖分项范围、整数约束、总分算术、未知状态、重复扣分和静态/交付隔离。
- 飞书“产物评分”新增 v0.2 字段并读回确认。
- Rubric SSOT 记录本版本及其与 `query-ppt-rubric@1.1.0` 的关系。
- 本版本不改变厂商 Runner、单次生成原则和重试策略。
