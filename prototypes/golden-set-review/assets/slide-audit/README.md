# SlideAudit sample assets

The six images in this directory are unmodified samples from
[zhuohaouw/SlideAudit](https://github.com/zhuohaouw/SlideAudit), pinned to
revision `642d490b7c1d2e78a50a631bfd359433397f3ecf`.

SlideAudit publishes its dataset under CC BY 4.0. These local copies are used
only to keep the Golden Set review prototype reproducible when GitHub Raw image
requests are delayed or unavailable.
